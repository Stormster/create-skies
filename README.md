# Create on Vulkan

Fabric 26.1.2 modpack (packwiz) for our server: Create Fly + Steam 'n' Rails, VulkanMod on the client.

- Clients: import `Create-on-Vulkan-Prism.zip` (see Releases) into Prism Launcher. It auto-updates from this repo on every launch.
- Server: itzg/minecraft-server with `PACKWIZ_URL` pointing at `pack.toml` (client-only mods are skipped).

Pinned on purpose (don't bump without testing): Create Fly 26.1.2-6.0.9-4, VulkanMod 0.6.8+26.1.2, Vulkan-Create Compat 0.1.0.

Add a mod: `packwiz modrinth add <slug>` then commit and push.
