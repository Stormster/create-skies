# Create Skies

NeoForge 1.21.1 modpack (packwiz): Create 6 + Create Aeronautics + Steam 'n' Rails, with Sodium, Iris and Distant Horizons on the client.

- Clients: import `Create-Skies-Prism.zip` (see Releases) into Prism Launcher. It auto-updates from this repo on every launch.
- Server: itzg/minecraft-server with `PACKWIZ_URL` pointing at `pack.toml` (client-only mods are skipped).

Add a mod: `packwiz modrinth add <slug>`, then commit and push. Both clients and the server pick it up on next launch/restart.
